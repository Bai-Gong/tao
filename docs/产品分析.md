# 百工·陶（Tao）产品分析

> 对标 Blender · 2026-10-19 留档

## 要做什么

**核心职能**：覆盖「建模—材质灯光—渲染出图」全链路的 3D 内容创作工具。

**必备核心能力**：

- 多边形建模：点/边/面编辑、布尔、细分、修改器堆栈（非破坏性）
- 场景管理：物体增删、层级父子、变换、相机与灯光
- 材质与渲染：PBR 材质、实时视口预览 + 离线渲染出图
- 基础操作与互操作：选择/吸附/轴心、OBJ/GLB 等导入导出

**可后置高级能力**：雕刻、UV 展开贴图绘制、几何节点（程序化）、动画与绑定、毛发/布料模拟、合成、脚本扩展。

## 页面呈现样式

**主界面五大区域**：中央 3D 视口（主体）；右上大纲 Outliner（场景树）；右侧属性面板（按修改器/材质/灯光等标签页组织）；底部时间轴；顶部工具栏与模式切换。

**工作区模式**：顶部标签在 Layout/建模/雕刻/UV 编辑/着色/动画/渲染等预置布局间切换，本质是同一套可停靠面板的不同排布。

**交互范式**：三键鼠标导航（中键旋转、Shift+中键平移、滚轮缩放）；Tab 切换物体/编辑模式；点选 + G/R/S 快捷变换；工具栏、饼菜单与拖拽式数值输入。整体强调快捷键驱动、模式化编辑、面板可自由拆分组合。

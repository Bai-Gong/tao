# 百工·陶（Tao）目标与里程碑

> 本文回答「做到什么、分几步、每步怎么算数」。为什么做见
> [产品分析.md](产品分析.md)。状态快照：2026-10-22（文档 + CI 阶段，
> 无业务代码）。

## 开发目标

「建模—材质灯光—渲染出图」全链路 3D 创作工具（对标 Blender 的
建模核心工作流），主打多边形建模与非破坏修改器栈；交互习惯对齐
Blender（G/R/S、饼菜单、模式切换）降低迁移成本。视口渲染以 wgpu
为基线（M0 评审确认与 Tauri WebView 的共存方案）；不依赖冶。

## 里程碑（每条以真实使用场景为准入）

- **M0 骨架**：Tauri 2 + React + 坊接入、wgpu 视口集成方案评审
  （窗口/表面共享）、OBJ/glTF 加载库选型。
  准入：应用窗口内实时渲染一个可旋转的立方体。
- **M1 视口与场景**：OBJ/GLB 导入渲染、相机导航（旋转/平移/缩放）、
  场景树（Outliner）。准入：流畅查看一个 10 万面级的真实第三方模型
  （帧率不卡顿、内存不失控）。
- **M2 变换与材质**：gizmo 变换（G/R/S）、父子层级、基础 PBR 材质
  编辑（金属度/粗糙度/贴图槽）。准入：摆一个多对象场景并调材质
  出图。
- **M3 建模最小集**：点/边/面选择与变换、挤出/环切/删除、撤销。
  准入：从立方体建出一个硬表面小模型（如音箱、桌椅）并导出 OBJ。
- **M4 修改器与 UV**：修改器栈（镜像/细分/布尔，非破坏求值顺序）、
  UV 展开基础、贴图查看。准入：完成一个带贴图的完整资产。
- **M5+（后置池，按需触发）**：雕刻、动画与绑定、离线渲染器、
  几何节点——产品分析「可后置」清单。

## 依赖与集群对齐

- 依赖坊：M0 起接入；陶与墨并列坊「第二工具铺开」（坊 M5）候选。
- 不依赖冶、不依赖纸（3D 导出为模型/图片格式）。
- 排期建议：与墨并行、在剪/锻主线之后启动；M0 的 wgpu + Tauri
  共存评审结论对后续任何需要 GPU 视口的项目（如墨的大画布）有
  复用价值，值得留档。

## 原则

- 每个里程碑以真实使用场景为准入条件，不为了齐备而齐备。
- 建模内核（半边结构/修改器求值）先正确后快；视口性能问题到
  M1 验收时再用真实模型压测。
